# Arch Linux Configuration

My personal Arch Linux configuration.

## Desktop

- Arch Linux
- Hyprland
- Waybar
- Kitty
- Rofi
- Mako
- Hyprpaper
- Hyprlock
- Starship
- Zsh

## Features

- macOS-inspired desktop
- Custom Hyprland keybindings
- Rofi application launcher
- Clipboard manager with Cliphist
- Custom screenshot scripts
- Custom wallpaper selector
- Wi-Fi menu through Rofi
- Custom power menu
- Starship prompt
- Zsh with autosuggestions and syntax highlighting
